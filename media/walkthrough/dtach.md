# dtach

dtach holds the terminal open so Pi keeps running when the sidebar is moved. Without it Pi starts over each time the view is dragged somewhere else; everything else still works, and a one-time warning says so.

- macOS: `brew install dtach`
- Debian and Ubuntu: `sudo apt install dtach`
- Windows: not available; leave this step alone

`piDock.dtachPath` points at it if it is off your PATH.
